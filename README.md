# Bovin De Souza main-site-v2

Astro rebuild of the Bovin De Souza personal portfolio, styled as a dark,
cinematic digital-studio site with a Three.js particle hero generated from the
original cover artwork.

## Commands

```sh
npm install
npm run dev
npm run build
npm run preview
```

## Vercel settings

- Framework preset: Astro
- Build command: `npm run build`
- Output directory: `dist`
